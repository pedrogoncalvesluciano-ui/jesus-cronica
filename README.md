# Jesus Crônica

Protótipo do motor de **Jesus Chronicles**, em HTML5, CSS3 e JavaScript puro com Canvas 2D e módulos ES.

## Executar

Sirva a pasta com um servidor estático:

```bash
python3 -m http.server 8000
```

Depois abra `http://localhost:8000/`.

## Testes

```bash
node tests/test-harness.mjs
```
